# خطيب — منصة تقييم الخطابة بالذكاء الاصطناعي

نظام يحلّل خطاب المتحدث ويُصدر تقريراً تقويمياً بدرجات رقمية، ومقاييس موضوعية محسوبة، وخطة تدريب أسبوعية، مع تتبّع تطوّر المتحدث عبر الجلسات.

مبني على: **n8n** (التنسيق) + **OpenAI** (Whisper للتفريغ، GPT-4o للتقييم) + **Supabase** (السجل) + **Vercel** (الواجهة والوسيط).

---

## ما الذي يجعله مختلفاً عن "لخّص لي الخطاب"

**1. مقاييس موضوعية محسوبة برمجياً — لا يخمّنها نموذج لغوي**

تُحسب في عقدة كود من نص التفريغ مباشرة، فهي أرقام قابلة للتكرار والتدقيق:

| المقياس | كيف يُحسب |
|---|---|
| عدد الكلمات والكلمات الفريدة | تقسيم مُطبَّع (إزالة تشكيل، توحيد الهمزات والتاء المربوطة) |
| ثراء المفردات | الكلمات الفريدة ÷ الإجمالي |
| سرعة الكلام (كلمة/دقيقة) | مقارنة بنطاق مرجعي للخطابة العربية (95–150) |
| كثافة التلكؤات | مطابقة قاموس حشو عربي على مستوى الرمز، مع تفصيل لكل نوع |
| متوسط طول الجملة | تقسيم على علامات الوقف |

هذه الأرقام تُمرَّر للنموذج **كحقائق مُلزمة**، مع تعليمات صريحة بعدم إعادة حسابها.

**2. مخرجات بمخطط JSON مُلزم (`strict: true`)**

كل استدعاء للنموذج يستخدم Structured Outputs من OpenAI بمخطط مُغلق. النتيجة: **استحالة عودة JSON مكسور** — وهي أكثر نقطة انهيار شائعة في هذا النوع من الأنظمة.

**3. مرحلتان منفصلتان: مُقيِّم ثم مدرّب**

- **الوكيل المُقيِّم** (حرارة 0.25): تقييم منهجي صارم، درجات 0–100 على ستة أبعاد بأوزان محددة، مع اقتباسات حرفية من النص كدليل. مُوجَّه صراحة بعدم المجاملة.
- **الوكيل المدرّب** (حرارة 0.55): يحوّل التقييم إلى خطة عملية داعمة، كل توصية مربوطة بدليل من الخطاب نفسه، وممنوع عليه النصائح العامة.

الفصل مقصود: التقييم الدقيق والتحفيز الداعم هدفان متعارضان في استدعاء واحد.

**4. تتبّع التطوّر عبر الجلسات**

قبل التقييم يُجلب سجل المتحدث من Supabase (مُطابَق بمفتاح اسم مُطبَّع)، فيقارن التقرير درجتك الحالية بالسابقة ويحدد ما تحسّن وما تراجع بالأرقام.

**5. صلابة تشغيلية**

إعادة محاولة تلقائية على كل عقدة شبكية، تجاوز آمن عند غياب السجل (المستخدم الجديد لا يتعطل)، رسائل خطأ عربية واضحة عند فشل التفريغ، وحفظ سجل التنفيذ للنجاح والفشل.

## البنية

```
index.html              واجهة المحادثة: تسجيل مباشر بالكاميرا/المايك أو رفع ملف،
                        وعرض التقرير كلوحة درجات ومقاييس
api/submit.js           دالة Vercel: تمرّر الطلب إلى نموذج n8n (تحل قيد CORS)
api/status.js           دالة Vercel: تمرّر استعلام حالة التنفيذ أثناء الانتظار
supabase_schema.sql     مخطط جدول speech_reports
workflows/              نسخ احتياطية من وركفلوهات n8n
```

### مسار التنفيذ

```
استلام الخطاب (نموذج + ملف + مدة التسجيل)
  → تجهيز الملف والتحقق منه
  → OpenAI Whisper (تفريغ عربي)
  → حساب المقاييس الموضوعية
  → جلب سجل المتحدث من Supabase
  → تجميع السياق (رقم الجلسة، الدرجة السابقة)
  → الوكيل المُقيِّم (مخطط JSON مُلزم)
  → الوكيل المدرّب (مخطط JSON مُلزم)
  → بناء التقرير النهائي
  → حفظ في Supabase → عرض للمستخدم
```

## النشر

### 1. Supabase
شغّل `supabase_schema.sql` في **SQL Editor**. راجع تنبيه RLS في نهاية الملف.

### 2. n8n
استورد الوركفلوهات من `workflows/`، واربط بيانات اعتماد **OpenAI** و**Supabase** (استخدم `service_role key`)، ثم فعّلها.

### 3. Vercel
**Add New → Project** → اختر هذا المستودع → Framework Preset: **Other** (بدون build command) → **Deploy**.

لا توجد متغيرات بيئة مطلوبة؛ روابط النماذج مكتوبة داخل دوال الـ API.

> إن غيّرت روابط نماذج n8n، حدّث `FORMS` في `api/submit.js` و`ALLOWED_PREFIX` في `api/status.js`.

## قيود معروفة — مذكورة صراحة لا مخفية

- **لا يوجد تحليل بصري.** المسار الحالي صوتي/نصي بالكامل، ولغة الجسد وتعابير الوجه والتواصل البصري **لا تُقيَّم ولا تُخمَّن** — النظام يصرّح بذلك في التقرير بدل أن يفبرك تقييماً. تفعيلها يتطلب نموذجاً يقرأ الفيديو بصرياً (مثل Gemini) في مسار منفصل.
- **البصمة الأسلوبية وصفية وليست بيومترية** — تصف أسلوب الإلقاء، ولا تُستخدم للتحقق من الهوية.
- **حد التنفيذ 180 ثانية** على n8n Cloud. المسار يشمل تفريغاً واستدعاءين لـ GPT-4o، لذا يُفضّل ألا تتجاوز التسجيلات 3 دقائق. التسجيلات الطويلة قد تتجاوز الحد.
- **سرعة الكلام تحتاج مدة التسجيل**، وترسلها الواجهة تلقائياً. عند الإرسال من نموذج n8n الخام مباشرة تظهر "غير متاحة" وتُستبعد من التقييم بدل تخمينها.
- **التسجيل المباشر يتطلب HTTPS** — متوفر تلقائياً على Vercel.

## الخصوصية

الملف الصوتي/المرئي يُمرَّر للتحليل ولا يُخزَّن في أي مرحلة — لا على Vercel ولا في n8n ولا في Supabase. المحفوظ هو التقرير ونصّ التفريغ والمقاييس، لغرض قياس التطوّر.
